# Deploying Aura

Aura is a Flask app. It needs: (1) somewhere to run, (2) a database that persists, and
(3) an email transport. This guide covers all three.

## 0. What you'll set up
- A **domain** (for professional sender email + good deliverability) — optional but recommended.
- **Resend** for email over HTTPS (works on hosts that block SMTP).
- A host: **Render** (easiest for Flask + persistent Postgres) or **Hugging Face Spaces** (Docker).

## 1. Get a domain (optional but recommended)
Buy one at Cloudflare Registrar, Namecheap, or Porkbun (~$1–12/yr). Any TLD is fine.
You only need it so email comes from e.g. `noreply@yourdomain.com` instead of a test sender.

## 2. Email with Resend
1. Sign up at https://resend.com.
2. **Domains → Add Domain** → enter your domain → add the shown DNS records (SPF/DKIM TXT)
   at your registrar → **Verify** (usually minutes).
3. **API Keys → Create** → copy the `re_...` key.
4. You'll set two env vars on your host:
   - `RESEND_API_KEY=re_...`
   - `MT_EVAL_EMAIL_FROM=Aura <noreply@yourdomain.com>`
No domain yet? You can still launch: with `MT_EVAL_EMAIL_FROM="Aura <onboarding@resend.dev>"`
Resend only delivers to the email that owns your Resend account. Verify a domain to email anyone.

## 3a. Host on Render (recommended)
1. Push this folder to a GitHub repo.
2. On https://render.com → **New → Blueprint**, pick the repo. Render reads `render.yaml`
   and creates a web service + a free Postgres database, wiring `DATABASE_URL` automatically.
3. In the service's **Environment**, set:
   - `MT_EVAL_ADMIN_EMAIL`, `MT_EVAL_ADMIN_PASSWORD` (your root admin login)
   - `RESEND_API_KEY`, `MT_EVAL_EMAIL_FROM`
   - (`MT_EVAL_SECRET_KEY` is auto-generated by the blueprint)
4. Deploy. Visit the URL, sign in with your admin email/password, create a campaign.
Notes: Postgres keeps your data across restarts/redeploys. The free web plan sleeps when idle
(first request after a nap is slow); the `starter` plan stays on.

## 3b. Host on Hugging Face Spaces (Docker)
1. Create a Space → **SDK: Docker**.
2. Upload this folder (it includes a `Dockerfile`). The Space builds and runs on port 7860.
3. **Settings → Variables and secrets** → add (as *Secrets*):
   - `MT_EVAL_SECRET_KEY` (a long random string), `MT_EVAL_ADMIN_EMAIL`, `MT_EVAL_ADMIN_PASSWORD`
   - `RESEND_API_KEY`, `MT_EVAL_EMAIL_FROM`
   - **`DATABASE_URL`** → strongly recommended. A Space's local disk is **ephemeral**: without
     an external DB, your SQLite data is wiped on every rebuild/restart. Use a free Postgres from
     Neon (https://neon.tech) or Supabase and paste its connection string here.
4. Restart the Space.

## 4. Other hosts
- **Railway / Fly.io**: same idea — deploy the repo (they detect the `Procfile`), add a Postgres
  plugin (sets `DATABASE_URL`), set the email + admin env vars.
- **Vercel**: not recommended for a long-running Flask app + SQLite; use Render/HF instead.

## 5. Required environment variables (summary)
| Variable | Purpose |
|---|---|
| `MT_EVAL_SECRET_KEY` | Flask session signing — set a long random value in production |
| `MT_EVAL_ADMIN_EMAIL` / `MT_EVAL_ADMIN_PASSWORD` | Your root admin login |
| `DATABASE_URL` | Postgres URL for persistent data (else local SQLite, ephemeral on most hosts) |
| `RESEND_API_KEY` + `MT_EVAL_EMAIL_FROM` | Email (OTP codes + results ZIP). Or SendGrid/SMTP. |
| `MT_EVAL_ADMIN_SIGNUP_ENABLED` / `_INVITE_CODES` / `_EMAIL_DOMAINS` | Lock down who can self-register (optional) |

## 6. After deploy — verify
- Open `/healthz` → should return `{"ok": true, ...}`.
- Sign in as admin → **Load demo data** to explore, or create a real campaign.
- Close a campaign → confirm the results ZIP arrives by email.
- If email fails, check the host logs; the error names the exact provider problem.

## Security checklist
- Set a strong `MT_EVAL_ADMIN_PASSWORD` and a random `MT_EVAL_SECRET_KEY`.
- Keep API keys in the host's secrets, **not** in git. Don't commit `.env`.
- Consider `MT_EVAL_ADMIN_INVITE_CODES` or `MT_EVAL_ADMIN_EMAIL_DOMAINS` so randoms can't self-register.
- Use HTTPS (Render and HF Spaces give you HTTPS automatically).
