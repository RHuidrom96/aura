Set a script per side when a language has more than one writing system. For machine translation you can specify the input (source) script, the output (target) script, or both (e.g. Assamese/Manipuri in Eastern Nagari vs. Meitei Mayek, Bodo in Devanagari, or a Roman transliteration). The dropdowns list only scripts valid for the chosen language. The same language on both sides is allowed only with two different scripts (a transliteration / script-conversion task).

Every segment is placed in one of three tiers: easy / medium / hard. The method only decides how segments are ranked; the split is always deterministic (equal thirds, or your custom length thresholds), so the same data groups the same way; it isn't a random choice. A per-segment difficulty field in your data overrides the computed tier (except when set to None). The campaign page shows the resulting easy/medium/hard counts.

When on, each annotator picks an expertise level when they register, and is shown only the matching difficulty: Beginner → Easy, Intermediate → Medium, Advanced → Hard. Leave off to assign difficulty yourself with the checkboxes below.
